# Copywriting

## Purpose
Write promotional copy that leads with a real benefit and stays honest.

## Core principles
- Outcomes over generic adjectives.
- No fake urgency or false scarcity.

## Practical rules
1. Identify audience and offer.
2. Lead with a benefit.
3. Support claims.
4. Flow from attention to action.
5. Keep copy as short as it can be while doing the job.

## When to activate
- Ads, landing pages, product copy, promo posts, CTAs.

## How to combine with other skills
- Use Persuasion for arguments.
- Use Brand Building for voice consistency.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Write a landing-page hero.
- Write a CTA.
