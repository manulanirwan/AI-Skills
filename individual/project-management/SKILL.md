# Project Management

## Purpose
Deliver projects against scope, time, and completion criteria.

## Core principles
- Activity is not completion.
- Scope changes must be explicit.

## Practical rules
1. Define deliverables and completion tests.
2. Map tasks and dependencies.
3. Track blockers.
4. Recover when milestones slip.
5. Review against original requirements.

## When to activate
- Planning, executing, and tracking a project.

## How to combine with other skills
- Use Planning for the first sequence.
- Use Process Design for a repeatable operation.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Run a two-week build.
