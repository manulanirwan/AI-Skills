# Data Analysis

## Purpose
Turn data into findings without confusing correlation with causation.

## Core principles
- Quality check first.
- Do not invent missing values.

## Practical rules
1. Define the question.
2. Understand columns, units, and population.
3. Find missing values, duplicates, and outliers.
4. Use appropriate comparisons.
5. Show important calculations.
6. State limitations.

## When to activate
- Datasets, comparisons, trends, calculations.

## How to combine with other skills
- Use Spreadsheet Skills for workbook work.
- Use Forecasting when projecting forward.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Analyze weekly signups.
