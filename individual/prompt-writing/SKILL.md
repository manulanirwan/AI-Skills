# Prompt Writing

## Purpose
Write prompts that control output without becoming contradictory or bloated.

## Core principles
- Specific enough to steer.
- Short enough to stay usable.
- Do not invent missing information.

## Practical rules
1. Define objective, task, context, constraints, and output format.
2. Remove ambiguity and contradiction.
3. Add examples only when they improve consistency.
4. Define how uncertainty should be handled.
5. Test edge cases mentally.

## When to activate
- New or improved prompts for text, image, video, code, or agents.

## How to combine with other skills
- Use Prompt Engineering skill files already in the workspace when present.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Tighten an image prompt.
- Write a structured extraction prompt.
