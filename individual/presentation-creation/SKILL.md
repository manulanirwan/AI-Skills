# Presentation Creation

## Purpose
Design slide structure with one purpose per slide and a clear main message.

## Core principles
- Message before slide list.
- No paragraph dumps.
- Never invent data.

## Practical rules
1. Identify audience and objective.
2. Define the main message.
3. Give each slide one purpose.
4. Keep on-slide text short.
5. Open with context and close on the message.
6. Use speaker notes when useful.

## When to activate
- Decks, pitches, lectures, tutorials.

## How to combine with other skills
- Use Public Speaking for delivery.
- Use the pptx skill when a .pptx file must be produced.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Outline a 10-slide pitch.
