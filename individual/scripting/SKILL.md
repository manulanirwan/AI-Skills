# Scripting

## Purpose
Write safe scripts for automation and admin tasks.

## Core principles
- Simple and reliable.
- Safeguards before destructive actions.

## Practical rules
1. Define input, process, and output.
2. Handle missing files, bad input, and command failures.
3. Quote paths.
4. Include a dry-run when practical.
5. Do not hardcode secrets.
6. Do not claim a script ran unless it did.

## When to activate
- Shell, PowerShell, Python, or similar scripts.

## How to combine with other skills
- Use Automation for workflow design.
- Use Linux Administration for system context.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Write a backup script with a dry-run.
