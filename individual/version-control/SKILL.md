# Version Control

## Purpose
Manage Git history safely.

## Core principles
- Warn before history-changing commands.
- Keep secrets out of the repo.

## Practical rules
1. Use focused commits and useful messages.
2. Explain merge, rebase, reset, and revert by effect.
3. Prefer safe recovery.
4. Do not rewrite shared history without stating the cost.

## When to activate
- Git branches, commits, merges, PRs, releases.

## How to combine with other skills
