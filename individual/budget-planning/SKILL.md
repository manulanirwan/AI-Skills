# Budget Planning

## Purpose
Allocate limited money with essentials first and totals checked.

## Core principles
- Estimates need evidence.
- Include contingency when appropriate.

## Practical rules
1. Define objective and period.
2. Split fixed, variable, one-time, and recurring costs.
3. Prioritize essentials.
4. Track actuals against plan.

## When to activate
- Personal, project, business, content, or operating budgets.

## How to combine with other skills
- Use Prioritization when items compete.
- Use Financial Analysis for performance.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Budget a 30-day content project.
