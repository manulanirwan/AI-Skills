# Explaining Complex Topics

## Purpose
Explain difficult ideas in layers without becoming inaccurate.

## Core principles
- Start simple and stay true.
- Label analogies as analogies.

## Practical rules
1. Estimate prior knowledge.
2. Define terms.
3. Break the subject into parts.
4. Use examples.
5. Cover common misconceptions.
6. End with what to remember.

## When to activate
- Hard technical, scientific, business, or abstract concepts.

## How to combine with other skills
- Use Technical Writing when the output is a document.
- Use Instruction Writing when the user must perform steps.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Explain DNS.
- Explain least privilege.
