# Forecasting

## Purpose
Reason about possible futures without presenting predictions as facts.

## Core principles
- A forecast is not a guarantee.
- Do not stretch a short trend forever.

## Practical rules
1. Define the question and time horizon.
2. Use current evidence and base rates.
3. Give more than one scenario.
4. Name leading indicators.
5. Label assumptions.
6. Do not invent future statistics.

## When to activate
- Expected outcomes, trends, project results, uncertain futures.

## How to combine with other skills
- Use Scenario Analysis to plan responses.
- Use Pattern Recognition for what has already been repeating.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Forecast whether a feature will reduce support tickets.
