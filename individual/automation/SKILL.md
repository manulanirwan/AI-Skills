# Automation

## Purpose
Turn a repetitive workflow into a reliable automated process.

## Core principles
- Do not automate a broken process as-is.
- Keep humans on high-risk actions.

## Practical rules
1. Map the current manual workflow.
2. Separate unattended steps from approval steps.
3. Handle failures, retries, duplicates, and partial completion.
4. Protect credentials.
5. Make automation reversible when practical.

## When to activate
- Repetitive business, technical, data, or content processes.

## How to combine with other skills
- Use Scripting for the script.
- Use Security Automation for security workflows.
- Use Process Design before automating.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Automate a report export.
