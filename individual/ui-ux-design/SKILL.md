# UI/UX Design

## Purpose
Design interfaces around real user tasks.

## Core principles
- Usability over decoration.
- No deceptive patterns.

## Practical rules
1. Identify the user and primary task.
2. Keep hierarchy and navigation clear.
3. Provide feedback for loading, success, failure, and empty states.
4. Consider accessibility and screen size.
5. Name concrete usability problems when reviewing.

## When to activate
- Apps, sites, dashboards, workflows.

## How to combine with other skills
- Use Web Development to implement.
- Use Customer Research for user evidence.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Review a signup flow.
