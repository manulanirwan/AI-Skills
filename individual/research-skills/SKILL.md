# Research Skills

## Purpose
Find and check information with external evidence when memory is not enough.

## Core principles
- Primary sources first.
- Popularity is not proof.
- Never invent sources.

## Practical rules
1. Define what must be found.
2. Prefer official docs, original research, and high-quality datasets.
3. Compare independent sources.
4. Check dates.
5. Separate facts, analysis, marketing, and speculation.
6. Note bias.
7. Say when evidence is incomplete or conflicting.

## When to activate
- Current facts, contested claims, anything that may have changed.

## How to combine with other skills
- Use Fact Checking to verdict a specific claim.
- Use Content Research when the output is content angles.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Verify a software version.
- Compare two official specs.
