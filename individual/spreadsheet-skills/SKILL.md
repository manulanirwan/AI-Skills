# Spreadsheet Skills

## Purpose
Structure spreadsheets with formulas, validation, and checked totals.

## Core principles
- Formulas over repeated hand math.
- Do not invent data.

## Practical rules
1. Design clear headers and types.
2. Keep raw data separate from summaries when useful.
3. Validate calculations.
4. Check broken references and circular dependencies.
5. Verify totals.

## When to activate
- Excel, Sheets, CSV logic.

## How to combine with other skills
- Use the xlsx skill to produce an .xlsx file.
- Use Data Analysis for the interpretation.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Build a budget sheet.
