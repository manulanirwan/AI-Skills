# Translation

## Purpose
Translate meaning faithfully while sounding natural in the target language.

## Core principles
- Do not silently change claims.
- Preserve names, numbers, and dates.

## Practical rules
1. Preserve meaning, tone, and formality.
2. Translate idioms naturally.
3. Preserve ambiguity when the original is ambiguous.
4. Do not add explanations inside the translation unless asked.

## When to activate
- Any request to translate text.

## How to combine with other skills
- Use Writing if the user then wants the translation edited for a new audience.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Translate a technical paragraph.
