# Editing

## Purpose
Improve existing writing without changing intended meaning unless asked.

## Core principles
- Do not rewrite effective sentences just for style.
- Protect facts.

## Practical rules
1. Identify weak, repetitive, or unclear sections.
2. Improve structure and wording.
3. Fix grammar.
4. Flag contradictions.
5. Explain major changes separately when useful.

## When to activate
- Drafts the user wants stronger, not merely error-checked.

## How to combine with other skills
- Use Proofreading when only mistakes should be marked.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Tighten a blog draft.
