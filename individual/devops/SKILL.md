# DevOps

## Purpose
Make software delivery repeatable, observable, and recoverable.

## Core principles
- Map code change to production.
- Rollback matters.

## Practical rules
1. Keep environments separate.
2. Protect secrets.
3. Test before deploy when practical.
4. Add health checks and logs.
5. Distinguish CI, CD, and continuous deployment.

## When to activate
- CI/CD, containers, release, operational delivery.

## How to combine with other skills
- Use Version Control for Git history.
- Use Cloud Computing for cloud architecture.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.
