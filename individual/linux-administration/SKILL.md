# Linux Administration

## Purpose
Administer Linux safely with distro-accurate commands.

## Core principles
- Least privilege.
- Do not mix incompatible distro instructions.

## Practical rules
1. Identify distro and version.
2. Explain impact before destructive commands.
3. Use the matching package manager.
4. Diagnose with logs, status, and process info.
5. Verify changes.

## When to activate
- Linux install, users, services, packages, logs, hardening.

## How to combine with other skills
- Use Networking for network-layer issues.
- Use Scripting for repeatable admin tasks.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Add a sudo user.
- Debug a failed systemd service.
