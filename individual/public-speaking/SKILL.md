# Public Speaking

## Purpose
Write and shape words meant to be spoken aloud.

## Core principles
- Spoken language, not essay language.
- Stay inside the requested time.

## Practical rules
1. Identify audience and objective.
2. Create a clear opening.
3. Keep sentences easy to say.
4. Mark pauses and emphasis when useful.
5. Anticipate questions.
6. Make the ending clear without exaggerated claims.

## When to activate
- Speeches, talks, spoken explanations, interview answers.

## How to combine with other skills
- Use Presentation Creation for slides.
- Use Voiceover Production for recorded delivery.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Prepare a 3-minute intro talk.
