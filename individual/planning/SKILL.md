# Planning

## Purpose
Turn a goal into an ordered sequence with a next action.

## Core principles
- Estimates are estimates.
- Essential steps before optional polish.

## Practical rules
1. Define the observable outcome.
2. State current position and resources.
3. Break work into actions.
4. Order by dependency.
5. Define milestones.
6. End with the immediate next action.

## When to activate
- Goals that need more than one step.

## How to combine with other skills
- Use Project Management to track after the plan exists.
- Use Budget Planning when money is the constraint.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Plan a learning path.
- Plan a launch.
