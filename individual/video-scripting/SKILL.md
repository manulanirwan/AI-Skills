# Video Scripting

## Purpose
Write spoken video scripts that match duration and stay factual.

## Core principles
- Spoken language.
- No fake stats.

## Practical rules
1. Define audience, platform, and message.
2. Open fast.
3. Keep visual notes separate from spoken words.
4. Pace Shorts tightly and long-form with structure.
5. Make the script recordable.

## When to activate
- Shorts or long-form scripts.

## How to combine with other skills
- Use YouTube Content for packaging.
- Use Voiceover Production for delivery.
- Use Content Research before factual claims.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Write a 45-second explainer.
