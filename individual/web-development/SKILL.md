# Web Development

## Purpose
Build or explain websites and web applications.

## Core principles
- Requirements before popularity.
- Secrets stay off the client.

## Practical rules
1. Identify users, pages, features, and constraints.
2. Separate frontend, backend, database, auth, API, and deploy.
3. Use semantic accessible HTML.
4. Handle loading, empty, error, and success states.
5. Validate input.
6. Match architecture to actual scale.

## When to activate
- Websites and web apps.

## How to combine with other skills
- Use Web Security for hardening.
- Use UI/UX Design for the experience.
- Use API Usage for API-only work.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Build a small authenticated app.
