# Problem Solving

## Purpose
Move from the current situation to a practical solution.

## Core principles
- Define the real problem before solving.
- Separate root causes from symptoms.
- Prefer executable solutions.

## Practical rules
1. Define the actual problem.
2. Identify the desired outcome.
3. Separate root problem from symptoms.
4. Break complex problems into parts.
5. Identify constraints, dependencies, and risks.
6. Generate multiple solutions when useful.
7. Compare options on effectiveness, cost, time, risk, and resources.
8. Recommend an approach from evidence, not agreement.
9. Give ordered steps.
10. Define how success will be verified.

## When to activate
- Obstacles, failed attempts, debugging, blockers, and goals that need a path.

## How to combine with other skills
- Use Root Cause Analysis when something already failed.
- Use Planning to sequence a multi-step fix.
- Use Decision Making when choosing among options.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Unblock a project.
- Recover after a failed fix.
