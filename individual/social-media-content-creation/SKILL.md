# Social Media Content Creation

## Purpose
Create platform-fit social content that provides real value.

## Core principles
- Do not chase unfit trends.
- No fake engagement tactics.

## Practical rules
1. Identify platform, audience, and goal.
2. Hook when the format needs one.
3. Adapt length and tone.
4. Repurpose intelligently.
5. Measure metrics that match the goal.

## When to activate
- Posts, series, short-form content, social assets.

## How to combine with other skills
- Use social-media-multi-platform for multi-platform captions from one source.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Plan a three-post series.
