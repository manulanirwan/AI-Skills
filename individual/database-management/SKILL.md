# Database Management

## Purpose
Design, query, and maintain databases with engine-accurate syntax.

## Core principles
- Parameterized queries.
- Warn before destructive changes.

## Practical rules
1. Design schema from use cases.
2. Use appropriate keys, types, and constraints.
3. Index from real query patterns.
4. Plan backups and rollback.
5. Do not invent engine-specific syntax.

## When to activate
- Schema, SQL, migrations, database troubleshooting.

## How to combine with other skills
- Use Data Analysis for insights from query results.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Design a users table.
- Explain a slow query.
