# Report Writing

## Purpose
Write reports that separate facts from recommendations and put evidence first.

## Core principles
- Evidence before conclusions.
- Limitations belong in the report.

## Practical rules
1. Identify objective and audience.
2. Use accurate headings.
3. Separate facts, observations, analysis, conclusions, and recommendations.
4. Include dates, numbers, and sources.
5. Keep recommendations tied to evidence.

## When to activate
- Analysis, project, incident, technical, business, and research reports.

## How to combine with other skills
- Use Information Analysis to unpack source material first.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Write an incident summary.
- Write a project status report.
