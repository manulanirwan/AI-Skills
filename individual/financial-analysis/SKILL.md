# Financial Analysis

## Purpose
Read business finances without inventing figures.

## Core principles
- Cash flow is not profit.
- Label estimates.

## Practical rules
1. Define the question and period.
2. Separate revenue, costs, profit, and cash.
3. Identify drivers.
4. Run scenarios.
5. Say what extra information is needed for high-stakes decisions.

## When to activate
- Revenue, costs, margins, cash, financial decisions.

## How to combine with other skills
- Use Budget Planning to allocate funds.
- Use Pricing Analysis for price-setting.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Check whether a side project covers costs.
