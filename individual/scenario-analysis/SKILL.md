# Scenario Analysis

## Purpose
Prepare responses for more than one realistic future.

## Core principles
- Robust actions work in more than one world.
- Do not rank scenarios by preference.

## Practical rules
1. Define situation, objective, and horizon.
2. Split controllable from uncontrollable variables.
3. Build expected, better, and worse cases that are still realistic.
4. Name triggers and responses.
5. Find actions that stay useful across scenarios.
6. Flag decisions that should wait.

## When to activate
- Important plans and decisions under real uncertainty.

## How to combine with other skills
- Use Forecasting for likelihood talk.
- Use Risk Assessment for a specific downside.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Plan a launch that still works if demand is weaker than hoped.
