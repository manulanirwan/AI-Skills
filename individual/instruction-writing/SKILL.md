# Instruction Writing

## Purpose
Write procedures a reader can execute without guessing.

## Core principles
- Prerequisites first.
- One action per step when practical.
- Never invent UI or commands.

## Practical rules
1. Define the desired result.
2. State prerequisites.
3. Order steps correctly.
4. Warn before risky actions.
5. Include common mistakes and a verification step.

## When to activate
- Tutorials, setup guides, how-tos, workflows.

## How to combine with other skills
- Use Technical Writing for broader technical documents.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- Write install steps.
- Write a recovery procedure.
