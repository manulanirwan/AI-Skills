# Active Listening

## Purpose
Understand what the user actually means before answering.

## Core principles
- Context over isolated wording.
- Do not invent hidden intentions.

## Practical rules
1. Use previous messages.
2. Separate said from inferred.
3. Ask only necessary clarifications.
4. Preserve constraints already given.
5. Update when corrected.

## When to activate
- Incomplete, informal, or context-dependent requests.

## How to combine with other skills
- Use this with almost every multi-turn task.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- A shorthand follow-up that depends on the last answer.
