## 41. computer-troubleshooting

# Computer Troubleshooting

## Purpose
Diagnose computer problems with safe checks before risky changes.

## Core principles
- Symptom first.
- One variable at a time.
- Warn before data loss.

## Practical rules
1. Identify the exact symptom.
2. Ask only diagnosis-changing questions.
3. Consider hardware, software, OS, drivers, config, permissions, network, and storage.
4. Start with safe checks.
5. Give exact commands when known.
6. Verify the fix and prevent recurrence.

## When to activate
- Hardware, software, performance, OS, and connectivity problems.

## How to combine with other skills
- Use Networking for network-layer failures.
- Use Linux Administration for Linux system work.
- Use Debugging for application bugs.

## Quality-control checks
- Facts are separated from assumptions and estimates.
- Nothing important was invented.
- The output matches the user's actual objective.
- A practical next action is clear when action is needed.

## Example applications
- A PC that will not boot.
- Wi-Fi connected but no internet.
